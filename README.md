# justfuckinguseamp

A static, independent fan site making the case for Amp's threads, orbs, and runners.

## Run locally

```bash
bun run dev
```

Open the local URL printed by Wrangler. The site is plain HTML and CSS with no client-side JavaScript.

## Deploy

```bash
bun run deploy
```

Wrangler serves and deploys the files in `src/` as Cloudflare Workers static assets.
